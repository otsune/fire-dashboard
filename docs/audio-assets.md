# 音源の準備

## 通常ビルドの同梱音源

`npm run dev` と `npm run build` は、12時間用・24時間用各24本のGemini TTS WAVとオリジナル4音チャイムを使います。外部音声の取り込みは不要です。音声は静的ファイルとして同梱し、再生時にGemini APIへ接続しません。

- 12時間用：`apps/dashboard/public/audio/gemini/12h/hour-00.wav` ～ `hour-23.wav`
- 24時間用：`apps/dashboard/public/audio/gemini/24h/hour-00.wav` ～ `hour-23.wav`
- 両形式ともWAV／PCM16、mono、24 kHz。MP3への再エンコードなし
- 元データ：2026-10-04に利用者がWindowsから提供したGemini TTSの結合WAV 2本
- 加工：各24本へ分割。境界の無音を含む元のPCM区間を保持し、リサンプリング・音量変更・フェード処理なし

正確な生成モデルとボイス名は元WAVから確認できていません。発話内容・順序も試聴／音声認識では未確認です。分割順に割り当てた予定原稿、各ファイルのSHA-256、形式、秒数は [provenance.json](../apps/dashboard/public/audio/gemini/provenance.json) にあります。`expected_text` は検証済みの文字起こしではありません。技術検査でWAVの読み取りやファイル一致を確認しても、発音や時刻の正しさは保証しません。

Gemini生成音声は公開リポジトリへの同梱を承認されたものです。Ayana音声や元の私用パッケージ・生成履歴は同梱しません。

### 出所と利用条件

コードと独自合成チャイムにはリポジトリの [Unlicense](../LICENSE) を適用します。Gemini生成音声は別扱いとし、[NOTICE.txt](../apps/dashboard/public/audio/gemini/NOTICE.txt) に出所と確認した規約を記載しています。Googleが音声をUnlicenseで提供したという意味ではなく、新たな音声ライセンスを付与するものでもありません。

[Gemini API Additional Terms「Use of Generated Content」](https://ai.google.dev/gemini-api/terms)では、Googleは生成内容の所有権を主張せず、利用者が適用法などに従い、共有先での利用にも責任を持つとしています。[Google APIs Terms第5条(e)](https://developers.google.com/terms)は、コンテンツの権利、出所の表示、権利表示の保持を扱っています。第三者の権利や各利用形態への適合を一律に保証するものではありません。確認日：2026-10-04。

## 同梱チャイム

`chime_Eb5_C5_Eb5_Ab5.wav` は、Eb5 → C5 → Eb5 → Ab5（レ♯ → ド → レ♯ → ソ♯）の採用音源です。既存録音のサンプリングや第三者音源を使わず、2026-10-03に数式から独自合成しました。

- PCM16、mono、48 kHz、3.2秒、307,244 bytes
- ピーク -12 dBFS、クリップなし
- SHA-256: `4486bbe635a74c647621f28c407e8b3067a523c11d0848110008961debcfab11`

「設定」→「時報の種類」→「チャイムのみ」を選び、時計に戻って「音声を有効にする」をタップすると試聴できます。ページを開く、設定を選ぶ、ビルドするだけでは鳴りません。

## 任意：外部の私用音声で上書きする

同梱Gemini音声の代わりに、手元の私用音声を形式ごとに上書きできます。外部の音声・元README・利用条件・provenanceは**リポジトリ外の私用フォルダー**に保管してください。外部音声には本リポジトリのUnlicenseを適用しません。

リポジトリのルートで実行します。各 `audio` ディレクトリには単一セットの `manifest.json` と、`hour-00` ～ `hour-23` のMP3またはWAVが必要です。ネイティブWAVもそのまま取り込み、MP3への再エンコードは行いません。manifestの `hours` は00〜23の各 `url`（例: `/audio/hour-00.wav`）と `license` を持ち、`chime` はnullで構いません。出力側のチャイムは同梱のものを維持します。

```sh
npm ci
npm run build:private-audio -- --12h /path/to/private-12h/audio --24h /path/to/private-24h/audio
npm run preview
```

Windows PowerShellの例（自分の展開先に置き換えてください）：

```powershell
npm run build:private-audio -- --12h "C:\private\12h\audio" --24h "C:\private\24h\audio"
npm run preview
```

`--12h` または `--24h` の片方だけでもビルドできます。指定しなかった形式は同梱Gemini音声のままです。従来の引数1つだけの指定は12時間用の上書きとして引き続き使えます。

このコマンドは指定した各セットの全24本・ファイル名・同一オリジンURL・権利情報・通常ファイルであることを確認してからビルドします。入力に欠損があれば以前のビルドを壊す前に停止します。音声ファイルのデコードや発音検査は行いません。

- 12時間用の上書き出力：`apps/dashboard/dist/audio/private/hour-00.mp3` 等（元の拡張子を維持）
- 24時間用の上書き出力：`apps/dashboard/dist/audio/private/24h/hour-00.wav` 等
- 出力の `/audio/manifest.json`：`hours` に12時間用、`hours24` に24時間用を登録。同梱チャイムと各音源のlicenseを維持
- 旧manifestの `hours` は12時間用として読み込み、24時間用へは流用しない
- 元ファイル、公開ソースのmanifest、設定の初期値：変更なし
- 私用README・provenance・生成履歴：配信ディレクトリへコピーしない
- 最後にService Workerを再生成し、音声とmanifestを版単位のオフライン資産に含める

`dist` はGit管理外ですが、外部の私用音声を取り込んだ**ビルド全体は私用として扱います**。公開デプロイやGitHubのartifact添付には使わないでください。配備は既存の[運用と認証](deployment.md)に従う管理作業です。このコマンドはサーバー、Fire、認証・管理者設定を変更しません。静的な私用音声ファイルにも配信のアクセス制限が必要です。

通常の `npm run build` を再実行すると同梱Gemini 48本とチャイムを使う配布物に戻ります。`npm run dev` と通常のE2Eテストも公開ソースを使うため、外部の私用音声の試聴には私用ビルド後の `npm run preview` を使用してください。外部の私用ZIP・MP3・WAV・メタデータはGitへ追加せず、ignore設定を強制解除しないでください。旧Ayanaセットも私用のまま保管し、公開配布物へ含めないでください。

## 再生前の確認

初期値は24時間表示・音声のみ（`voice`）です。チャイムを先に鳴らすには「設定」→「時報の種類」→「チャイムと音声」を選びます。「12時間表記」がONなら12時間用、OFFなら24時間用の音声に自動で切り替わります。時刻表示と別の音声形式スイッチはありません。

時計に戻って「音声を有効にする」をタップすると、選択モードで00時の試聴をして有効化します。「チャイムと音声」ならチャイム → 300 ms → 00時の音声です。「試聴」は10時の音声です。自動時報は設定タイムゾーンの00～23に対応し、静音時間と前面表示の条件を守ります。

形式変更は再生中・待機中の音声を停止し、変更操作そのものでは鳴りません。同梱音源には両形式が揃っています。独自manifestなどで形式が欠ける場合だけ「24時間表記の音声が未設定」等と表示し、その形式の音声／両方モードを有効化できません。別形式での代用はしません。未設定の形式へ切り替えると音声は無効になり、用意済みの形式へ戻しても再度タップが必要です。チャイムのみはどちらの表示形式でも使えます。

更新済みの画面では「更新して再読み込み」で新しい資産一式に切り替えてから再度有効化してください。前のService Workerが動いたままだと旧manifestが使われます。私用音声を取り除いた場合も更新の切替を完了し、古いキャッシュが残らないことを確認してください。

実際のFireの前面ブラウザーで両形式の全24本を聞き、時刻・読み・音量を確認してから常設運用してください。特に4時・7時・9時・深夜・正午を確認します。以下は予定原稿であり、録音の内容を確認済みという意味ではありません。

## 時刻補正と再生権の安全性

ブラウザーのWeb Locksに対応している場合は、実際に生きているタブの排他権を持ってからIndexedDBの再生リースを確保します。時計が前進しても、別タブの再生中の権利を時刻だけで奪いません。対応ブラウザーではタブが終了するとWeb Lockが解放され、残ったリースも次の排他的な取得時に回復できます。

Web Locks未対応の場合は、安全のため他の所有者のリースを時刻だけで自動回収しません。タブの強制終了などで権利が残ると音声が停止したままになる場合があります。その場合はすべての同一ダッシュボード画面を閉じたことを人が確認してから、そのサイトの保存データを消去し、設定と音声の有効化をやり直してください。保存されたカードと時報履歴も消えます。実機の対応状況は未確認です。

保留中の時報も無効化、非表示、設定変更、時刻補正、10秒の期限超過で破棄します。音声を鳴らさなかった記録も再試行しません。
